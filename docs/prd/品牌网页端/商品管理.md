# 品牌网页端 — 商品管理

## 1. 页面基本信息

| 项目 | 说明 |
|------|------|
| **页面名称** | 商品管理（商品概览） |
| **页面入口** | 商品列表 |
| **对应原型** | 品牌网页端页面原型 |
| **页面类型** | 信息展示 / 只读列表 |
| **角色权限** | 品牌运营人员（仅查看） |

---

## 2. 页面概述

商品管理页面是品牌运营人员查看当前品牌下所有上架商品信息的核心页面。页面以「商品卡片网格」的形式展示商品的基本信息，包括商品分类、名称、适用车型、库存和销量，帮助品牌方快速了解商品矩阵和销售表现。

该页面目前为**只读展示型**页面，品牌运营人员可在此浏览商品信息，但暂不支持直接编辑商品。如需修改商品信息，需联系平台管理员或通过其他入口操作。

---

## 3. 功能描述

本页面核心功能包括：品牌商品列表展示、商品信息概览查看、销量统计展示。

---

## 4. 功能分析

- **商品列表展示**：以卡片网格形式展示当前品牌下所有商品。
- **商品信息展示**：每张卡片展示商品分类、名称、适用车型、库存和销量。
- **只读标识**：页面头部标注"仅展示"，提示用户当前页面不可编辑。

---

## 6. 功能详细说明

### 6.1 商品列表展示

**用户场景**
品牌运营人员需要了解当前品牌下有哪些商品在售，各自的库存和销量如何。

**前置条件**
- 已进入"商品概览"标签页。
- 示例数据 中已定义商品数据（商品列表），且存在属于当前品牌的商品。

**需求描述**
- 页面展示"商品概览"板块，头部包含：
 - 英文标签 `Products
 - 中文标题 商品概览
 - 右侧"仅展示"标签（标签），提示当前页面为只读
- 商品以卡片网格形式展示（品牌-web-商品列表）。
- 若品牌下无商品，网格为空（当前代码未单独处理空状态）。

**后置条件**
- 运营人员可浏览品牌下的所有商品信息。

**补充说明**
- 商品通过 品牌商品 函数筛选，即 数据的商品列表 中 品牌 字段等于当前品牌名称的商品。

---

### 6.2 商品信息展示

**用户场景**
品牌运营人员需要查看某个商品的具体信息，例如库存是否充足、销量表现如何。

**前置条件**
- 已在商品概览页面看到商品卡片。

**需求描述**
- 每张商品卡片展示以下信息：
 - **商品分类**：如"轮毂"、"制动"、"车衣"等（条目的分类）
 - **商品名称**：如"BBS FI-R 20寸锻造轮毂"（名称，加粗）
 - **适用车型 / 库存 / 销量**：以小字展示，格式为 `{fit个人中心nt} / 库存 {库存} / 销量 {sales}
- 卡片为纯展示，无点击交互。

**后置条件**
- 运营人员可获取商品的分类、名称、适配车型、库存和销量数据。

**补充说明**
- 销量数据通过 销量统计 函数计算，优先取商品自身的 `sales` / `sold` / 销量统计 字段，若不存在则取品牌层面的销量数据。

---

### 6.3 只读标识

**用户场景**
品牌运营人员初次进入商品页面，需要明确知道当前页面是否可以编辑商品。

**前置条件**
- 已进入商品概览页面。

**需求描述**
- 板块头部右侧展示"仅展示"标签（`span 类别="标签"`）。
- 标签为灰色中性风格，明确提示用户当前页面不支持编辑操作。

**后置条件**
- 用户明确当前页面为只读，不会尝试寻找编辑入口。

**补充说明**
- 当前品牌端暂不提供商品编辑功能，实际生产环境中如需支持，需在平台管理端或品牌端增加商品编辑表单。

## 8. 备注

- 当前为演示版本，商品数据为预设示例数据。
- 本页面为**只读展示页**，不提供新增、编辑、删除、上下架等商品管理操作。
- 商品销量数据存在多字段备用逻辑，实际生产环境应统一销量统计口径。
- 页面无空状态处理，若品牌下无商品，网格区域将完全空白；实际生产环境建议增加"暂无商品"提示。
- 品牌端商品管理权限较轻，重度的商品维护操作（新增、改价、库存调整）应在平台管理端完成。
