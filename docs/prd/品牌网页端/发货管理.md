## 一、引言

### 1、编写目的

发货管理页面是品牌运营人员查看已发货订单和跟踪物流状态的核心页面。页面展示当前品牌下所有已确认发货的订单列表，每条订单显示物流公司和物流单号，方便品牌方进行履约回顾和物流查询。

该页面与"待发货订单"页面形成完整的订单履约闭环，解决了品牌方"发货后需要查看历史发货记录和物流信息"的需求。

### 2、背景

满改平台是一个高端汽车改装服务系统，涵盖用户端 App、服务商端 App、平台网页端、品牌网页端和管理员端 App。

## 二、任务概述

### 1、产品定位

满改平台是面向高端汽车改装领域的综合服务平台，连接车主用户、改装服务商和品牌供应商，提供从内容种草、方案咨询、商品采购到施工履约的一站式改装服务。

### 2、产品目标

通过平台化运营，提升改装行业的服务标准化水平和交易透明度，降低用户决策成本，帮助服务商拓展客源，实现多方共赢。

### 3、目标用户与使用场景

目标用户包括：有改装需求的车主、提供改装服务的服务商门店、管理平台的运营人员、品牌供应商。

### 4、用户的特点

车主用户注重改装品质与安全性，决策周期较长，需要案例参考和专业建议。服务商关注订单获取效率与结算周期。

### 5、岗位与角色

| 角色/岗位名称 | 职责 | 权限 | 描述 |
| ------ | ------ | ------ | ------ |
| 品牌运营 | 发货记录查询、物流跟踪 | 查看品牌已发货订单 | 负责核对发货记录和跟进物流异常 |

### 6、假定和约束

当前实现为前端静态原型，所有数据仅保存在示例数据中，刷新页面后恢复初始数据。

## 五、功能需求

### 1、功能描述

本页面核心功能包括：已发货订单列表展示、物流信息查看、空状态处理。

### 2、功能分析

· **已发货订单列表**：展示当前品牌下所有已发货的订单及物流信息。
· **物流信息查看**：每条已发货订单展示物流公司和物流单号。
· **空状态处理**：若无已发货订单，展示友好的空状态提示。

### 3、用户角色

| 角色/岗位名称 | 职责 | 权限 | 描述 |
| ------ | ------ | ------ | ------ |
| 品牌运营 | 发货记录查询、物流跟踪 | 查看品牌已发货订单 | 负责核对发货记录和跟进物流异常 |

### 4、数据字典

| 数据项 | 来源变量 | 来源文件 |
| ------ | ------ | ------ |
| 品牌订单列表 | 数据的订单列表（过滤品牌关联） | 示例数据 |
| 发货记录 | 本地记录.数据读取 | 本地记录 |
| 订单物流信息 | 订单物流信息 / 物流公司 / 物流单号 | 示例数据 + 本地存储 |
| 订单收件信息 | 订单的recipient / 订单的手机号 / 订单的地址 | 示例数据 |

### 5、功能详细说明

#### 5.1 已发货订单列表

**用户场景**

品牌运营人员需要查看历史发货记录，核对物流信息或回答用户的物流咨询。

**前置条件**

- 已进入"已发货订单"标签页。
- 本地记录 中已存在发货记录，或订单数据中已有发货状态。

**需求描述**

- 页面展示"已发货订单"板块，头部包含：
 - 英文标签 `Shipped
 - 中文标题 已发货订单
- 调用 页面展示 渲染已发货订单列表，第二个参数 `shipped = 是。
- 每条已发货订单展示：
 - 订单编号（加粗）
 - 服务/商品名称
 - 用户名称
 - 订单金额
 - 状态：已发货
 - 收件信息（收件人 / 电话 / 地址）
 - 物流公司名称和物流单号

**后置条件**

- 运营人员可浏览所有已发货订单的物流信息。

**补充说明**

- 已发货订单通过 品牌订单的对应功能处理 筛选。
- 物流信息优先从 订单物流信息 对象读取，若不存在则从 物流公司 / 物流单号 读取。

---

#### 5.2 物流信息查看

**用户场景**

用户咨询物流进度时，品牌运营人员需要快速找到对应订单的物流公司和单号。

**前置条件**

- 已在已发货订单列表中。

**需求描述**

- 每条已发货订单在列表中直接展示物流信息：
 - 标签"物流"
 - 值：`{物流公司} {物流单号}
- 若物流信息缺失，显示"-"。

**后置条件**

- 运营人员可直接复制物流单号提供给用户或查询物流轨迹。

**补充说明**

- 物流信息为静态展示，无点击跳转第三方物流查询的功能。
- 实际生产环境可接入快递 100 等物流查询接口，点击单号跳转查询页面。

---

#### 5.3 空状态处理

**用户场景**

品牌方刚开始运营，还没有已发货订单。

**前置条件**

- 已进入"已发货订单"标签页。
- 当前品牌下无任何已发货订单。

**需求描述**

- 当 页面接收到的 `rows` 为空列表时，展示空状态文案：
 - 暂无已发货订单
- 空状态区域采用统一的空状态样式（品牌-web-empty`）。

**后置条件**

- 用户明确知道当前没有已发货记录。

**补充说明**

- 空状态文案由 订单列表 的 `shipped` 参数控制，为 是 时显示"暂无已发货订单"。
