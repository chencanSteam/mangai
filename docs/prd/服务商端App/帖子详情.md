## 一、引言

### 1、编写目的

### 2、背景

满改平台是一个高端汽车改装服务系统，涵盖用户端 App、服务商端 App、平台网页端、品牌网页端和管理员端 App。

---

## 二、任务概述

### 1、产品定位

满改平台是面向高端汽车改装领域的综合服务平台，连接车主用户、改装服务商和品牌供应商，提供从内容种草、方案咨询、商品采购到施工履约的一站式改装服务。

### 2、产品目标

通过平台化运营，提升改装行业的服务标准化水平和交易透明度，降低用户决策成本，帮助服务商拓展客源，实现多方共赢。

### 3、目标用户与使用场景

目标用户包括：有改装需求的车主、提供改装服务的服务商门店、管理平台的运营人员、品牌供应商。

### 4、用户的特点

车主用户注重改装品质与安全性，决策周期较长，需要案例参考和专业建议。服务商关注订单获取效率与结算周期。

### 5、岗位与角色

| 角色/岗位名称 | 职责 | 权限 | 描述 |
| ------ | ------ | ------ | ------ |
| 服务商管理员 | 内容创作与帖子管理 | 全部功能 | 已入驻服务商，可查看、点赞、收藏、分享自己的帖子，可删除/恢复 |
| 论坛版主 | 板块内容秩序维护 | 额外版主权限 | 已通过版主申请的服务商，可管理板块内帖子 |

## 五、功能需求

### 1、功能描述

本页面核心功能包括：帖子内容展示、多媒体正文浏览、关联商品展示、评论互动（查看/发布/删除）、点赞与收藏、分享传播、帖子状态管理（删除/恢复）、版主操作。

### 2、功能分析

· **帖子头部信息**：展示标题、作者、发布时间、分类、浏览量等元信息。
· **互动操作栏**：支持点赞、收藏、分享、删除帖子。
· **正文内容展示**：支持图文混排、视频嵌入、标签展示。
· **关联商品挂载**：展示帖子关联的平台商品，支持点击跳转商品详情。
· **评论互动区**：展示热门回复列表，支持发布新回复、删除自己的回复。
· **帖子管理面板**：在运营中心内展示帖子互动数据、状态、商品链接权限、挂载商品、创作者主页状态。

### 5、功能详细说明

#### 5.1 帖子头部与内容展示

**用户场景**

服务商或用户通过链接进入帖子，需要了解帖子的主题、作者和核心内容。

**前置条件**

- 独立页面：通过 链接参数 帖子 指定帖子标识，如 `?帖子=night-cruise-评价
- 运营中心：已从论坛列表中选中某条帖子

**需求描述**

1. **独立页面形态**（独立页面）：
 - 顶部导航栏：标题「帖子详情」，副标题「社区内容」
 - 帖子主卡片（帖子-hero-卡片）：
 - 分类标签：帖子-详情-overline`（如「夜拍精选」）
 - 帖子标题：大号字体（如「魔都午夜巡游改装盛典回顾」）
 - 帖子摘要：一句话描述核心价值
 - 元信息网格（帖子-个人中心ta-网格）：作者、发布时间、分类、浏览量
 - 正文卡片（帖子-article-卡片）：
 - 多媒体网格：图片组、视频片段（带播放按钮）
 - 文章正文：多段落文字内容
 - 标签行（帖子-标签-row#轮毂尺寸#避震高度
2. **运营中心形态**（帖子管理面板）：
 - 以 管理员-详情-卡片 面板展示
 - 英文标签 ，标题为帖子标题
 - 键值对展示：互动数据、当前状态、商品链接权限、已挂商品、创作者主页状态

**后置条件**

内容加载完成，可进行互动操作。

**补充说明**

- 独立页面底部展示App底部导航栏，便于用户随时跳转其他模块。
- 若帖子已被删除（ 中 帖子删除标记 标记），展示「帖子已删除」提示页。

#### 5.2 互动操作栏

**用户场景**

服务商浏览帖子时，需要对内容进行点赞、收藏、分享或删除操作。

**前置条件**

帖子处于正常展示状态。

**需求描述**

1. 独立页面在帖子主卡片底部展示互动操作栏（帖子-engage-bar`），包含4个按钮：
 - **赞**（帖子L点赞按钮）：显示当前点赞数（默认98），点击切换点赞/取消状态
 - **藏**（帖子C收藏按钮）：显示当前收藏数（默认26），点击切换收藏/取消状态
 - **享**（帖子S分享按钮）：点击打开分享面板
 - **删除帖子**（帖子D删除按钮）：红色文字，点击确认后删除帖子
2. 点赞和收藏状态持久化至 （帖子互动状态记录）。
3. 点赞/收藏后数字实时更新（点赞数 ±1，收藏数 ±1）。

**后置条件**

互动状态更新，数字实时变化。

**补充说明**

- 删除帖子需二次确认（确认 对话框），删除后展示「帖子已删除」提示页，并提供返回按钮。
- 删除状态持久化至 （帖子删除状态记录）。

#### 5.3 分享功能

**用户场景**

服务商希望将优质帖子分享至微信、朋友圈、抖音，或复制链接、分享给平台用户。

**前置条件**

点击「享」按钮。

**需求描述**

1. 从底部弹出分享面板（分享-sheet`），包含：
 - **外部分享**：微信、朋友圈、抖音、复制链接
 - **平台用户分享**：展示前8位平台用户，点击即可分享给指定用户
 - **取消按钮**
2. 点击「复制链接」调用 导航栏的clipboard.文本写入，提示「链接已复制」。
3. 点击「微信/朋友圈/抖音」调用 导航栏的分享（若支持），否则提示「请使用分享功能」。
4. 点击平台用户头像提示 。

**后置条件**

分享面板关闭，根据分享类型给出对应反馈。

**补充说明**

- 分享面板为前端模拟实现，未接入真实微信/抖音 SDK。

#### 5.4 关联商品展示

**用户场景**

帖子内容与特定商品相关（如改装案例中使用的产品），需要在帖子中挂载商品链接以便用户直接购买。

**前置条件**

帖子已关联至少一个商品。

**需求描述**

1. 独立页面在正文下方展示「关联商品」区块（帖子-链接ed-商品-卡片）。
2. 每个关联商品以卡片形式展示：
 - 商品图片占位
 - 商品名称（如 ）
 - 品牌 / 类目 / 适配车型
 - 价格（如 ）
3. 点击商品卡片跳转至商品详情页（独立页面）。

2. 运营中心形态在帖子管理面板中以列表展示已挂商品名称、价格、品牌、类目、适配车型。

**后置条件**

点击后跳转商品详情页。

**补充说明**

- 商品链接权限（链接认证状态）控制是否允许挂载商品，未授权时不可挂载。

#### 5.5 评论互动区

**用户场景**

服务商和用户希望在帖子下方发表评论、参与讨论，或管理不当评论。

**前置条件**

帖子处于正常展示状态。

**需求描述**

1. **评论列表**（帖子-评论列表-卡片）：
 - 顶部展示评论总数（如 ）
 - 每条评论包含：头像（首字母）、用户名、发布时间、评论内容
 - 每条评论提供「删除」按钮（独立页面中可删除自己的评论）
2. **发布回复**（帖子-reply-卡片）：
 - 多行文本输入框，占位符 为 `说说你的看法，参与这条热门帖子的讨论...
 - 「清空」按钮：清空输入框
 - 「发布回复」按钮：提交评论
3. 评论发布流程：
 - 校验内容非空
 - 将新评论追加到 （评论数据记录）
 - 评论列表顶部插入新评论，显示「我」和「刚刚」
 - 更新评论总数
 - 提示 `回复已发布，已同步到帖子互动区。
4. 评论删除流程：
 - 点击「删除」按钮，从页面元素中移除评论
 - 在 中将对应评论标记为 状态: "删除d"
 - 提示 `评论已删除。

**后置条件**

评论列表更新，评论数变化。

**补充说明**

- 评论数据持久化至 ，刷新页面后仍保留（已删除的评论不再显示）。
- 评论总数 = 初始24条 + 用户新增的未删除评论数。

#### 5.6 帖子状态管理

**用户场景**

服务商需要对自己发布的帖子进行删除或恢复操作，或在运营中心快速查看帖子数据。

**前置条件**

处于运营中心「论坛管理」Tab，并已选中某条帖子。

**需求描述**

1. 帖子管理面板（帖子管理面板）展示以下数据：
 - **互动**：回复数 / 点赞数
 - **当前状态**：正常 / 已删除（论坛状态映射）
 - **商品链接权限**：已授权 / 未授权
 - **已挂商品**：商品名称列表或「未挂商品」
 - **创作者主页**：置顶作品 / 未置顶
2. 操作按钮：
 - 「查看评论」：可跳转独立帖子详情页
 - 「删除帖子」/「恢复显示」：切换帖子状态
3. 点击「删除帖子」后，帖子状态变为「已删除」；点击「恢复显示」后恢复为「正常」。

**后置条件**

帖子状态变更，在论坛列表中同步更新标签。

**补充说明**

- 版主已通过的服务商还拥有「管理板块」权限，可删除违规帖子、置顶优质内容。
- 帖子状态变更即时生效，不涉及二次确认。
