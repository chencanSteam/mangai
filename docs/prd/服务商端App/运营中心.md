## 一、引言

### 1、编写目的

运营中心是服务商端App的综合性运营后台，聚合了门店日常运营所需的五大子模块：配件采购、采购记录、服务定价、案例管理和论坛管理。服务商可在此完成配件选品与采购、查看历史采购记录、配置门店服务报价、上传改装案例并提交审核，以及管理论坛帖子与申请版主权限。

### 2、背景

满改平台是一个高端汽车改装服务系统，涵盖用户端 App、服务商端 App、平台网页端、品牌网页端和管理员端 App。

---

## 二、任务概述

### 1、产品定位

满改平台是面向高端汽车改装领域的综合服务平台，连接车主用户、改装服务商和品牌供应商，提供从内容种草、方案咨询、商品采购到施工履约的一站式改装服务。

### 2、产品目标

通过平台化运营，提升改装行业的服务标准化水平和交易透明度，降低用户决策成本，帮助服务商拓展客源，实现多方共赢。

### 3、目标用户与使用场景

目标用户包括：有改装需求的车主、提供改装服务的服务商门店、管理平台的运营人员、品牌供应商。

### 4、用户的特点

车主用户注重改装品质与安全性，决策周期较长，需要案例参考和专业建议。服务商关注订单获取效率与结算周期。

### 5、岗位与角色

| 角色/岗位名称 | 职责 | 权限 | 描述 |
| ------ | ------ | ------ | ------ |
| 服务商管理员 | 门店运营与内容管理 | 全部功能 | 已入驻服务商，可采购、定价、管理案例和论坛 |

## 五、功能需求

### 1、功能描述

本页面核心功能包括：配件采购（选品、采购、下单）、采购记录查询与签收、服务定价配置、案例增删改查与审核提交、论坛帖子管理与版主申请。

### 2、功能分析

· **配件采购**：浏览平台可采购商品网格，查看商品详情，填写采购数量、支付方式、收货地址并提交采购。
· **采购记录**：查看历史采购订单列表，查看记录详情，确认收货。
· **服务定价**：为门店启用的服务项目设置报价，报价需在平台规定的价格区间内。
· **案例管理**：新增、编辑改装案例，上传图片，关联商品，提交平台审核。
· **论坛管理**：查看门店发布的帖子列表，申请论坛版主，删除/恢复帖子，管理帖子挂载商品。

### 5、功能详细说明

#### 5.1 配件采购

**用户场景**

服务商需要为门店补货配件（如轮毂、车衣、刹车套件等），在平台商城中选品并下单采购。

**前置条件**

- 服务商已入驻并通过审核
- 中 商品列表存在可采购商品

**需求描述**

1. 子Tab「配件采购」以网格卡片形式展示可采购商品（可采购商品，取前4条）。
2. 每张商品卡片包含：
 - 商品名称、品牌、类目
 - 适配车型说明
 - 价格
3. 点击商品卡片进入商品详情页（商品采购详情）：
 - 大图标展示、品牌、型号、类目、价格、库存状态
 - 「立即采购」按钮
4. 点击「立即采购」展开采购表单（采购表单）：
 - **采购数量**：数字输入框，范围 1-99，默认1
 - **支付方式**：下拉选择（支付宝 / 微信支付）
 - **收货地址**：下拉选择，默认选中门店地址
 - **采购备注**：文本输入框，默认 门店补货采购
5. 点击「确认采购」后生成采购记录，状态为「待发货」，自动跳转「采购记录」Tab。

**后置条件**

生成一条新的采购记录，商品库存（示例层面）相应扣减。

**补充说明**

- 收货地址来源于 地址信息，包含门店默认地址和自定义地址。

---

#### 5.2 采购记录

**用户场景**

服务商需要跟踪已采购商品的物流状态，并在到货后确认签收。

**前置条件**

已存在至少一条采购记录。

**需求描述**

1. 子Tab「采购记录」以列表形式展示历史采购订单（采购记录）。
2. 每条记录展示：
 - 记录编号（如 `PO-240402`）
 - 商品名称 / 型号
 - 数量 / 金额
 - 状态标签（待发货 / 已签收）
3. 点击记录展开详情面板（商品详情面板，record模式）：
 - 商品、型号、数量、金额、支付方式、收货地址、状态、进度说明
 - 操作按钮：「确认收货」（未签收时）或「已确认收货」（ 禁用 ）
4. 点击「确认收货」后，记录状态更新为「已签收」，进度说明更新。

**后置条件**

记录状态变为「已签收」，可用于后续安装或入库安排。

**补充说明**

- 采购记录存储在 服务商P采购记录 列表中，持久化至页面刷新前。

---

#### 5.3 服务定价

**用户场景**

服务商需要根据平台指导价区间，为门店设置各项改装服务的实际报价，报价将用于咨询、派单和服务下单展示。

**前置条件**

- 中 `services` 列表已定义平台服务项

**需求描述**

1. 子Tab「服务定价」顶部展示定价规则摘要：
 - 当前门店名称
 - 已启用服务项数量
 - 平台定价规则（报价需在平台区间内）
 - 报价用途说明
2. 每个服务项以卡片形式展示：
 - 服务名称
 - 「当前可接」复选框（停用项不可勾选）
 - 平台价格范围（只读）
 - 门店报价输入框（数量，步长100，需在 最小-最大 区间内）
 - 状态标签（启用 / 停用）、建议价标签、纳入报价状态标签
3. 底部提供「保存定价」和「恢复建议价」按钮。
4. 保存时自动校验：
 - 低于最小值自动调整为最小值
 - 高于最大值自动调整为最大值
 - 统计并提示自动调整项数

**后置条件**

服务定价状态更新至 当前页面，可用于后续派单报价展示。

**补充说明**

- 停用状态的服务项不可启用，也不可修改报价。

---

#### 5.4 案例管理

**用户场景**

服务商需要将门店的优秀改装案例上传至平台，通过审核后在用户端展示，以获取潜在客户信任并关联商品销售。

**前置条件**

- 服务商已入驻并通过审核

**需求描述**

1. 子Tab「案例管理」顶部提供「新增案例」按钮。
2. 案例列表展示已有案例（案例，前4条），每条展示：
 - 案例标题
 - 车型 / 改装类型 / 费用区间
 - 审核状态标签（待提交 / 待审核 / 已通过 / 未通过）
 - 展示状态标签（展示中 / 未展示）
3. 点击案例展开详情面板（案例详情面板）：
 - 车型、改装类型、费用区间、审核状态、展示状态
 - 关联商品列表（如有）
 - 操作按钮：「提交审核」、「编辑案例」
4. 新增/编辑案例表单（案例编辑表单）包含：
 - **案例标题**：文本输入
 - **车型**：文本输入
 - **费用区间**：文本输入
 - **改装类型**：下拉选择（车衣改造 / 轮毂改造）
 - **上传图片**：文件选择器，最多9张
 - **案例说明**：多行文本
 - **关联商品**：按类目分组的多选框，勾选平台商品进行关联
5. 点击「提交审核」后，案例审核状态变为「待审核」。

**后置条件**

新增/编辑的案例进入案例列表，提交审核后等待平台运营人员审批。

**补充说明**

- 案例创建时审核状态为「待提交」，展示状态为「未展示」。
- 只有审核通过的案例才能在用户端展示。

---

#### 5.5 论坛管理

**用户场景**

服务商作为内容创作者，需要在论坛发布改装相关内容、管理已发布帖子，并可申请成为版主以获得更高的内容管理权限。

**前置条件**

- 服务商已入驻并通过审核

**需求描述**

1. 子Tab「论坛管理」顶部提供版主操作按钮：
 - 「申请版主」（未申请时）/ 「审核中」（待审核时）/ 「版主权限管理」（已通过时）
 - 「管理板块」（已通过时显示）
2. 帖子列表展示门店关联帖子（论坛帖子，前4条），每条展示：
 - 帖子标题
 - 作者、发布时间、分类
 - 互动数据（回复 / 点赞）
 - 状态标签
3. 点击帖子展开详情面板（帖子管理面板）：
 - 互动数据（回复 / 点赞）
 - 当前状态（正常 / 已删除）
 - 商品链接权限（已授权 / 未授权）
 - 已挂商品列表
 - 创作者主页状态（置顶 / 未置顶）
 - 操作按钮：「查看评论」、「删除帖子」/「恢复显示」
4. 版主申请表单（版主申请表单）包含：
 - 申请门店、主营类目（只读）
 - 申请管理板块：下拉选择（JDM 专区 / 欧系性能）
 - 申请理由：多行文本
5. 提交申请后，版主状态变为「待审核」，平台将在3个工作日内完成审核。

**后置条件**

版主申请提交后等待平台审核；帖子删除/恢复操作即时生效。

**补充说明**

- 已通过版主的服务商可使用「管理板块」功能删除违规帖子、置顶优质内容。
- 帖子详情中的「查看评论」可跳转至独立帖子详情页面。
