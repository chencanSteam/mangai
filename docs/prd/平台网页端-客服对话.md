## 1. 页面基本信息

| 项目 | 说明 |
|------|------|
| **页面名称** | 客服对话 |
| **页面入口** | 客服对话 |
| **对应原型** | 平台网页端页面原型 |
| **页面类型** | 即时对话（Chat） |
| **角色权限** | 平台客服 / 运营管理员 |

---

## 2. 页面概述

客服对话是平台运营人员处理**用户与服务商主动向平台发起咨询**的统一入口。与「聊天记录」（仅查看订单关联的用户-服务商对话）不同，客服对话支持平台客服以**官方身份介入回复**，并标记会话处理状态。

---

## 4. 模块详细说明

### 4.1 会话列表（左侧边栏）

**尺寸**：固定宽度 固定宽度，高度自适应
**样式**：深色面板，圆角 圆角

#### 4.1.1 列表头部
- **左侧**：`会话列表 (N)` — 显示总会话数量
- **右侧**：`M 条未读` — 显示未读消息总数

#### 4.1.2 会话项

每个会话项为可点击按钮，包含：

| 元素 | 说明 |
|------|------|
| 左侧头像 | 圆形渐变背景，显示对方名称首字（如「德」「顾」） |
| 对方名称 | 加粗显示 |
| 时间 | 最新消息时间，如「刚刚」「5 分钟前」 |
| 会话标题 · 角色 | 如「入驻咨询 · 服务商」 |
| 消息预览 | 最新消息内容，单行截断 |
| 状态标签 | 未处理(警告状态) / 处理中(信息) / 已解决(成功状态) |
| 未读徽标 | 数字红点，显示未读条数 |

**交互**：
- 点击会话项：切换右侧对话详情，清除该会话未读数
- 当前选中会话：高亮显示（橙红色边框 + 背景）

#### 示例数据

### 4.2 对话详情（右侧主区域）

#### 4.2.1 顶部信息栏
- ** eyebrow 标签**：用户咨询 或 服务商咨询
- **标题**：会话主题，如「入驻咨询」
- **副标题**：`对方名称 · 当前状态
- **操作按钮**：
 - 标记处理中（仅状态为「未处理」时显示）
 - 标记已解决（状态非「已解决」时显示）

#### 4.2.2 消息气泡区域

**样式**：复用现有 `.对话-气泡 样式体系

| 发送方 | 对齐 | 背景色 | 角色标签 |
|--------|------|--------|---------|
| 平台客服 | 右侧 | 橙红色系 (平台-气泡) | 平台客服 |
| 用户 | 左侧 | 默认 (用户-气泡) | 用户 |
| 服务商 | 左侧 | 默认 (`服务商-气泡) | 服务商 |

每条消息显示：
- 角色标签（如「平台客服」「用户」）
- 发送时间
- 消息文本内容

#### 4.2.3 底部输入框

**布局**：横向排列
- **输入框**：单行文本输入，占位符 `输入回复内容，按 Enter 发送
- **发送按钮**：按钮-主色调，文字「发送」

**交互**：
- 点击「发送」：将消息追加到当前会话末尾，发送方固定为 平台
- 按 `Enter` 键：触发发送
- 发送后：自动更新会话预览文本、时间为「刚刚」
- 若原状态为「未处理」，自动变为「处理中」

## 5. 交互说明

### 5.1 页面加载
1. 管理员从左侧菜单点击「客服对话」。
2. 页面展示 识别 配置的类型 等于 "对话"`，调用 页面展示。
3. 默认选中第一个会话（或首个有未读的会话）。
4. 调用 事件绑定 绑定所有交互事件。

### 5.2 发送消息流程

输入内容 → 点击发送 / 按 Enter
 ↓
校验非空
 ↓
向 消息列表 添加 新消息（, 当前时间）
 ↓
更新会话 上一个iew、ti个人中心、状态（未处理→处理中）
 ↓
清空输入框
 ↓
重新渲染页面（重新加载客服对话页面与侧边栏）
 ↓
左侧菜单徽标同步更新


### 5.3 状态标记
| 操作 | 触发条件 | 结果 |
|------|---------|------|
| 标记处理中 | 点击顶部「标记处理中」按钮 | 状态变为「处理中」 |
| 标记已解决 | 点击顶部「标记已解决」按钮 | 状态变为「已解决」 |
| 自动标记 | 客服首次发送消息时 | 未处理 → 处理中 |

## 7. 与「聊天记录」的区别

| 维度 | 客服对话（本页面） | 聊天记录（原有页面） |
|------|-------------------|---------------------|
| 对话发起方 | 用户/服务商 → 平台客服 | 用户 ↔ 服务商 |
| 平台角色 | 可主动回复 | 仅旁观/追溯 |
| 状态管理 | 未处理 / 处理中 / 已解决 | 沟通中 / 待验收 / 售后中 |
| 操作能力 | 发送消息、标记状态 | 仅查看、跳转订单 |
| 数据字段 | 客服会话 | 订单Chats |

## 8. 备注

- 当前为演示版本，所有消息仅作临时保存，刷新页面后恢复为初始数据。
- 未接入真实的 实时通信 或消息推送，多客服同时在线时的消息同步需后端支持。
- 页面采用平台统一的深色主题，与「聊天记录」弹窗共用 `.对话-气泡 消息气泡样式体系。
