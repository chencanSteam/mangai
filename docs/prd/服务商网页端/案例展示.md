# 服务商网页端 — 案例展示

## 1. 页面基本信息

| 项目 | 说明 |
|------|------|
| **页面名称** | 门店展示 / 案例展示 |
| **页面入口** | `showcase` |
| **对应原型** | 服务商网页端页面原型 |
| **页面类型** | 信息展示 / 门店官网 |
| **角色权限** | 服务商（已入驻） |

---

## 2. 页面概述

案例展示页面是服务商在平台上的"线上门店"，面向潜在用户展示门店形象、主推服务、精品案例和联系方式。页面以「门店 Hero 区 + 案例滚动展示 + 主推服务 + 门店位置」的多板块结构呈现，是服务商吸引用户预约到店和获取订单的重要转化入口。

该页面解决了服务商"如何在平台上展示专业形象并获取客户线索"的问题，是平台连接服务商与用户的核心桥梁。

---

## 3. 功能描述

本页面核心功能包括：门店形象展示、案例滚动切换、主推服务列表、门店位置信息展示、联系与转化。

---

## 4. 功能分析

- **门店 Hero 展示**：顶部大卡片展示门店名称、标语、合同信息、认证标签和门店视觉。
- **案例滚动展示**：侧边栏展示精品案例，支持上一条/下一条切换。
- **门店数据统计**：展示门店核心数据指标（如案例数、评分、月订单等）。
- **主推服务列表**：展示门店提供的核心改装服务和参考价格。
- **门店位置信息**：展示门店所在区域、详细地址和营业时间。
- **联系与转化**：展示服务热线与门店认证标签。

## 6. 功能详细说明

### 6.1 门店 Hero 展示

**用户场景**
潜在用户或服务商自己需要一眼了解门店的核心信息和专业定位。

**前置条件**
- 已进入"门店展示"标签页。
- 示例数据 中已定义服务商门店数据。

**需求描述**
- 页面顶部左侧为大型 Hero 卡片，包含：
 - **门店名称**：大号标题（如"御驰 Performance Studio"）
 - **标语与区域**：如"上海闵行 / 高端改装展示中心"
 - **认证标签**：展示门店前 3 个认证标签（标签 样式）
 - **合同与状态标签**：合同编号、合同状态、详细地址
 - **门店视觉区**：展示"门店主视觉"标签、标语、业务定位描述
 - **数据统计网格**：展示门店核心指标卡片（如案例数、评分、月订单、服务数等）

**后置条件**
- 用户或服务商可快速获取门店的核心形象和关键数据。

**补充说明**
- 门店数据来自 门店 对象，指标数据来自 门店的统计 列表，最多取前 4 项。
- 门店视觉区为占位设计，实际生产环境应支持上传门店主图。

---

### 6.2 案例滚动展示

**用户场景**
潜在用户想了解该门店的施工案例和质量水平。

**前置条件**
- 已进入门店展示页面。
- 门店下存在案例（门店案例 返回非空列表）。

**需求描述**
- 右侧边栏展示"案例滚动展示"板块。
- 板块头部包含标题"案例滚动展示"和导航按钮：
 - "上一条"（按钮-次色调）
 - "下一条"（按钮-主色调）
- 中间展示区展示当前选中的案例标题。
- 点击导航按钮可切换展示不同案例。
- 若门店暂无案例，展示提示"当前暂无案例。"

**后置条件**
- 用户可浏览门店的精品案例，了解施工水平。

**补充说明**
- 案例切换通过修改 当前页面 实现，循环展示。
- 当前仅展示案例标题，实际生产环境应展示案例封面图和详情摘要。

---

### 6.3 主推服务列表

**用户场景**
潜在用户想了解该门店提供哪些改装服务以及大致价格区间。

**前置条件**
- 已进入门店展示页面，滚动至主推服务板块。

**需求描述**
- 页面下方左侧展示"主推服务"板块。
- 以服务列表形式展示门店提供的核心服务，每项包含：
 - **服务名称**（如"全车隐形车衣"）
 - **服务描述**（如"TPU材质，全车包边包角"）
 - **参考价格**（如"¥ 3600"），以 标签 警告状态 样式展示
- 服务数据来自 展示服务 列表，最多展示 4 条。

**后置条件**
- 用户可了解门店的服务范围和参考价格。

**补充说明**
- 服务数据从 平台数据中的services` 中过滤提取，排除状态为"停用"的服务。
- 价格为演示数据，实际应以门店报价为准。

---

### 6.4 门店位置信息展示

**用户场景**
潜在用户想了解门店的具体位置和营业时间，以便预约到店。

**前置条件**
- 已进入门店展示页面，滚动至门店位置板块。

**需求描述**
- 页面下方右侧展示"门店位置"板块。
- 以列表形式展示：
 - **所在区域**：如"上海闵行"，标签"定位信息"
 - **详细地址**：完整地址，标签"可导航"
 - **营业时间**：如"09:30 - 21:00"，标签"欢迎到店"

**后置条件**
- 用户可获取门店的位置和营业时间信息。

**补充说明**
- 地址和营业时间来自 门店 对象，标签为固定配色。
- 实际生产环境可接入地图组件，点击"可导航"标签跳转地图导航。

---

### 6.5 联系与转化

**用户场景**
潜在用户看完门店展示后，想联系门店或预约到店。

**前置条件**
- 已进入门店展示页面，看到右侧"联系与转化"板块。

**需求描述**
- 右侧下方展示"联系与转化"板块，包含：
 - **服务热线卡片**：展示服务热线（如"400-908-6608"），说明支持预约到店看车、案例讲解、实车方案报价
 - **认证标签**：展示门店全部认证标签
**后置条件**
- 用户可通过服务热线联系门店，或继续浏览页面其他内容。

**补充说明**
- 实际生产环境应支持一键拨号或在线客服入口。

## 8. 备注

- 当前为演示版本，门店数据为预设示例数据。
- 案例展示区目前仅展示案例标题，实际生产环境应展示案例封面图、车型、费用等更丰富信息。
- 门店展示页是服务商在平台上的"线上门面"，信息准确性和视觉呈现直接影响用户转化率。
- 页面布局采用响应式设计，在大屏幕上为左右两栏，小屏幕上堆叠展示。
