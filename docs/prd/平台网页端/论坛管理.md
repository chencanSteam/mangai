# 平台网页端 — 论坛管理

## 1. 页面基本信息

| 项目 | 说明 |
|------|------|
| **页面名称** | 论坛管理 |
| **页面路由/标识** | `forumManage` |
| **对应文件** | `assets/js/platform-web.js`（`renderForumManagePage()` 函数） |
| **页面类型** | 内容管理 / 社区运营 |
| **角色权限** | 平台管理员（运营/审核） |

---

## 2. 页面概述

论坛管理页面是平台运营团队对社区帖子进行集中审核、管理和运营操作的核心页面。页面以「筛选标签 + 帖子卡片流」的形式呈现全站论坛内容，运营人员可在此查看帖子基本信息、互动数据、状态标签，并通过点击帖子卡片进入详情抽屉，执行置顶、加精、删除、商品链接管理等操作。

该页面解决了社区内容合规监控、优质内容推荐和违规内容处置的问题，是平台 UGC 运营的重要工具。

---

## 3. 功能描述

本页面核心功能包括：帖子列表筛选与展示、帖子状态标签展示、帖子详情查看与内容管理、评论区管理、处理轨迹查看。

---

## 4. 功能分析

- **帖子列表筛选**：通过顶部筛选标签切换不同状态的帖子分组（如全部、正常、已删除等）。
- **帖子卡片展示**：以卡片流形式展示帖子标题、作者、互动数据和状态标签。
- **帖子详情查看**：点击帖子卡片打开右侧详情抽屉，展示帖子完整信息和操作按钮。
- **帖子状态操作**：支持置顶/取消置顶、加精/取消加精、删除/恢复帖子、设置主页置顶作品。
- **商品链接管理**：查看和管理帖子关联的商品链接。
- **评论区管理**：查看帖子下的评论列表，支持删除/恢复单条评论。

## 6. 功能详细说明

### 6.1 帖子列表筛选

**用户场景**
运营人员想查看特定状态的帖子，例如只关注已删除帖子进行复核，或查看待审核的新帖。

**前置条件**
- 已进入论坛管理页面
- `mock-data.js` 中已定义帖子数据 `posts`

**需求描述**
- 页面顶部 toolbar 左侧展示一排筛选标签按钮（如"全部"、"正常"、"已删除"等）。
- 点击标签后，帖子列表只展示符合该筛选条件的帖子。
- 当前激活的筛选标签高亮显示（`active` 类）。
- 切换筛选时，`selectedIndex` 重置为 0。

**后置条件**
- 帖子列表重新渲染，展示筛选后的结果。
- 若无符合条件的帖子，列表区域显示"暂无内容"。

**补充说明**
- 筛选条件由页面定义 `def.filters` 提供。
- 筛选逻辑由 `filterRows()` 通用函数处理。

---

### 6.2 帖子卡片展示

**用户场景**
运营人员需要一览社区内的帖子概况，快速识别高互动内容、违规内容或需要运营干预的帖子。

**前置条件**
- 页面已加载，帖子数据已通过 `def.rows` 传入。

**需求描述**
- 以卡片流形式展示帖子，每张卡片包含：
  - **帖子标题**（`title`）
  - **元信息行**：作者（`author`）、发布时间（`time`）、回复数（`replies`）、点赞数（`likes`）、浏览量（`views`）
  - **帖子摘要**（`content`），截取部分内容展示
  - **状态标签组**：置顶状态（`topStatus`）、加精状态（`featuredStatus`）、链接认证状态（`linkAuthStatus`）、主页置顶（`creatorPinned`）、帖子状态（`status`）
  - **底部信息**：帖子 ID、作者、关联商品数量（`linkedProducts`）
- 当前选中的帖子卡片高亮显示（`active` 类）。
- 卡片可点击，点击后打开右侧详情抽屉。

**后置条件**
- 选中状态更新，`selectedIndex` 同步到全局 state。
- 触发 `openPlatformDetailModal()` 或抽屉展示帖子详情。

**补充说明**
- 帖子状态标签使用 `formatTag()` 渲染，不同状态对应不同颜色：
  - 正常 → success（绿色）
  - 已删除 → danger（红色）
  - 置顶/加精 → warning（琥珀色）
- 浏览量使用 `toLocaleString("zh-CN")` 格式化千分位。

---

### 6.3 帖子详情查看与内容管理

**用户场景**
运营人员需要对单条帖子进行精细化管理，例如将优质内容置顶推荐，或删除违规帖子。

**前置条件**
- 已在帖子列表中点击某条帖子卡片。

**需求描述**
- 在详情抽屉/模态框中展示帖子的完整信息：
  - **标题与标签**：帖子标题 + 所有状态标签（置顶、加精、已删除等）。
  - **基础信息**：以键值对形式展示作者、发布时间、状态、互动数据等。
  - **评论区**：展示该帖子下的所有评论列表。
  - **处理轨迹**：以时间轴形式展示该帖子的审核和操作记录。
  - **操作按钮区**：
    - 删除帖子 / 恢复帖子
    - 置顶 / 取消置顶
    - 加精 / 取消加精
    - 商品链接
    - 主页置顶作品 / 取消主页置顶

**后置条件**
- 运营人员执行操作后，帖子状态更新，列表重新渲染。
- 删除/恢复操作会同步更新帖子的 `status` 字段。

**补充说明**
- 帖子详情由 `renderForumDetail()` 函数渲染。
- 操作按钮的状态（如显示"恢复帖子"还是"删除帖子"）根据当前帖子状态动态判断。

---

### 6.4 评论区管理

**用户场景**
运营人员发现某条评论存在违规内容，需要单独删除该评论而不影响帖子本身。

**前置条件**
- 已进入帖子详情抽屉。
- 该帖子下存在评论数据。

**需求描述**
- 在详情抽屉的"评论区"板块展示该帖子下的所有评论。
- 每条评论展示：评论作者、发布时间、评论内容、状态标签。
- 已删除评论额外展示删除原因（`deleteReason`）。
- 每条评论右侧提供操作按钮：
  - 若评论状态为正常 → 显示"删除评论"
  - 若评论状态为已删除 → 显示"恢复显示"

**后置条件**
- 评论状态更新后，评论区列表重新渲染。

**补充说明**
- 评论数据来自 `comments` 数组，通过 `post.id` 关联。
- 评论状态与帖子状态共用 `nForum()` 状态映射函数。

---

### 6.5 处理轨迹查看

**用户场景**
运营人员需要追溯某条帖子的历史操作记录，了解之前谁审核过、做过什么操作。

**前置条件**
- 已进入帖子详情抽屉。

**需求描述**
- 在详情抽屉的"处理轨迹"板块以时间轴形式展示该帖子的操作历史。
- 每条记录为一个时间节点，按时间倒序排列。

**后置条件**
- 运营人员可查看完整的帖子生命周期记录。

**补充说明**
- 处理轨迹数据来自帖子对象的 `timeline` 数组。

## 7. 数据源

| 数据项 | 来源变量 | 来源文件 |
|--------|---------|---------|

---

## 8. 备注

- 当前实现为前端静态原型，所有帖子、评论数据为预置 mock 数据。
- 帖子状态操作（删除、置顶、加精）仅修改前端内存中的数据，刷新页面后恢复初始状态。
- 商品链接管理按钮目前为占位功能，实际生产环境需接入商品关联接口。
